Need help with Wings ERP?

This page demonstrates the embeddable SupportDesk chat widget. Open the chat bubble in the bottom-right corner, start a conversation, ask for a person to hand the chat to an agent (it creates a ticket and notifies agents), and reply from the agent desk under Conversations.

Bot first

An assistant answers when one is configured; otherwise the chat goes straight to an agent.

Verified identity

"Verify my e-mail" sends a one-time code and links the chat to your contact record.
